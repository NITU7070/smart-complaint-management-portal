# Smart Complaint Management Portal (NagrikSeva)

A web-based grievance redressal system designed to help citizens submit, track, and manage complaints efficiently. The platform improves transparency and accountability by enabling real-time complaint tracking, automated department assignment, and resolution monitoring.

## Features

* Submit and track complaints using a unique tracking ID
* Category-based auto-routing to relevant departments
* Anonymous complaint submission option
* SLA-based monitoring and escalation workflow
* Department dashboard for complaint management
* Interactive analytics and performance insights
* File upload support for evidence and documents
* Resolution feedback and rating system
* Dark/Light mode toggle
* Fully responsive design for desktop and mobile devices

## Technology Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## Project Highlights

This project simulates a real-world complaint management system used by government agencies and service organizations. It focuses on improving complaint resolution workflows, monitoring service-level agreements (SLAs), and providing a user-friendly experience for both citizens and administrators.

## Future Enhancements

* Backend integration with Node.js and Express
* Database support using MongoDB/MySQL
* Email and SMS notifications
* Geo-location based complaint mapping
* AI-powered complaint prioritization
